📌 1. If-Clauses 3 แบบที่ออกสอบทุกปี

• Type 1 (เป็นไปได้ในอนาคต): If + Present Simple, S + will + V.inf
• Type 2 (สมมุติในปัจจุบัน/ไม่จริง): If + Past Simple (V.2/were), S + would + V.inf
• Type 3 (สมมุติในอดีตที่ผ่านไปแล้ว): If + had + V.3, S + would have + V.3

🎖️ 2. คำศัพท์ภาษาอังกฤษทางทหาร (Military Vocabulary)

• Soldier = ทหาร | Commander = ผู้บังคับบัญชา
• Weapon = อาวุธ | Ammunition = กระสุนปืน
• Mission = ภารกิจ | Strategy = ยุทธศาสตร์ / กลยุทธ์
• Perimeter = แนวกระจายกำลัง / ขอบเขตพื้นที่รักษาความปลอดภัย
