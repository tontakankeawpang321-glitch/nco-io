🧮 1. สูตรคณิตศาสตร์ที่ออกสอบบ่อยที่สุด
1. สูตรผลบวกเลขเรียง 1 ถึง n
Sum = n(n + 1) / 2 (เช่น 1 ถึง 100 = 100x101/2 = 5,050)
2. สูตรงานและคน (ปริมาณงานคงที่)
คน1 x วัน1 x ชม.1 = คน2 x วัน2 x ชม.2
3. สูตรความเร็ว ระยะทาง และเวลา
ระยะทาง (s) = ความเร็ว (v) x เวลา (t)
4. กำไร ขาดทุน และร้อยละ
ราคาขาย = ทุน x (1 + กำไร%) | กำไร% = (กำไร / ทุน) x 100
